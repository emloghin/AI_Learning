About This Site and How to Give Feedback

AI Learn is a personal learning project by Emanuel Loghin. This page explains who made it, how the content is checked, and how to report a mistake or suggest an improvement.

1. Who made this

AI Learn is written and maintained by Emanuel Loghin as a personal project, built while learning the subject and kept as a guide others can follow.

It is not an official publication of any employer, and it is not affiliated with, sponsored by or endorsed by any AI model provider, GitHub, Microsoft or the makers of the tools it describes. Opinions and recommendations are the author's own.

2. How to give feedback

Corrections are the most valuable feedback. Tools in this area change every few weeks, so something that was right when it was written may be wrong now.

You want to… Do this
Report an error, a broken link or an outdated command Open an issue in the GitHub repository
Suggest a topic or an improvement Open an issue in the same place and describe who would benefit
Propose a concrete change Open a pull request against the Markdown file in ai-fundamentals/docs
Write to the author directly Send an e-mail to loghin.emanuel@yahoo.com
Connect or send a message Find the author on LinkedIn

A useful report says:

  • which page and section (copy the heading, or the address from your browser);
  • what is wrong or unclear, in one or two sentences;
  • what you expected instead, with a link to a source if you have one;
  • for commands: the tool version you used and what happened when you ran it.

Please do not include passwords, API keys, customer data or other confidential information in an issue or an e-mail. Issues in a public repository are visible to everyone.

3. How the content is made and checked

  • Sources first. Statements about tools are taken from official documentation, tagged releases and source code, and each page links to them. Community reports are labelled as experiences, not as rules.
  • Dates and versions are stated. Hands-on pages say which version they describe and when they were last checked. The agent and spec-driven chapters were last checked on 27 November 2026.
  • AI assistance, human responsibility. The pages were drafted and fact-checked with the help of AI coding assistants, using the same review habits this course teaches: independent verification against primary sources, and a person who reads and approves the result. The author is responsible for the content.
  • What is not guaranteed. Commands were checked against documentation, but not every command was run on every platform. Treat the walkthroughs as a guide, try them in a throwaway repository first, and trust your installed tool's own help when it disagrees with this site.

4. Using this material

You are welcome to read, share links to and learn from this site. If you want to reuse larger parts of the text or the diagrams, ask through the feedback channel above first.

The site contains no tracking and stores nothing about you on a server. Your study progress, ticked checklists and theme choice are saved only in your own browser and can be cleared by clearing the site's data.

5. Not professional advice

This is educational material. It is not legal, security or compliance advice. References to laws and standards, such as the EU AI Act, are summaries with links to the official texts; for decisions that matter, read the original and consult the responsible people in your organization.
